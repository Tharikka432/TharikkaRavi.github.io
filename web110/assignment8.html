Activity 1: Test Your Firewall Using ShieldsUP I tested my laptop using the Gibson Research ShieldsUP website. The result showed that the equipment at the target IP address did not respond to the UPnP probes, which is good news. Let's talk about the possible results: Exposed, Rejected, and No Response. These results can vary depending on the type of internet equipment being used. Exposed is probably not a good result. Hacking packets are constantly being detected across the Internet. Scanning is underway, and the threat is real. An exposed result can show hackers exactly which version of UPnP firmware you are running, making it easier for them to find ways to attack the device. Rejected is better news. This equipment is not fully "stealthful" because it does respond to probing attempts. However, it still blocks unwanted access, which provides protection. The last result is No Response, which is also good news. The device does not respond to any probes, making it more difficult for attackers to detect or identify it. Activity 3: Research Password Managers and Multi-Factor Authentication A password manager is software that stores usernames and passwords in a secure collection called a password vault. Most password managers save and organize your passwords in one place. Some can also synchronize records between devices and allow users to share credentials with others. By using a password manager, you can create and store a different password for each account, which reduces the need to remember many passwords. Security depends on how well the vault is protected and on features such as autofill, synchronization, sharing, and account recovery. Password managers have existed since the 1990s and later became available as browser extensions and built-in browser features. Multi-factor authentication (MFA) adds an extra layer of security to an account. Instead of only requiring a password, MFA asks for another form of verification, such as a code sent to your phone, an authentication app, or a fingerprint. This makes it much harder for attackers to access an account, even if they know the password.
