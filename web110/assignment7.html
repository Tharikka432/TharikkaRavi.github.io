Activity 1 (Revised & Humanized) TutorialsPoint: Internet reference models Reference models offer a way of standardization that is accepted worldwide. Since people use more and more network devices, we need standardized models — a reference model. The OSI model is the acronym for Open System Interface, also an ISO standard. There are many layers. The Physical layer activates the connection, defines voltages, and converts digital bits into electrical signals. The Data Link layer enables error detection and adds error‑detection bits to the data that will be transmitted. It also performs synchronization. The Network layer routes data, acts on addressing, divides outgoing messages into packets, and assembles incoming packets into messages for higher levels. The Transport layer decides how to deliver data, performs flow control, and breaks data groups into smaller units so they can be handled more efficiently by the network layer. The Session layer manages and controls sessions, user identification, billing, and session management. The Presentation layer makes sure the information is delivered in a form the receiving system will understand and use. The Application layer provides functions such as login or password checking. Now let’s talk about the TCP/IP model, which is used on the internet. There are Transmission Control Protocol and Internet Protocol. The TCP/IP model also has layers: Application, Transport, Internet, and Host‑to‑Network. The Application layer uses protocols such as TELNET, FTP, SMTP, DNS, HTTP, and NNTP. These are all the layers and how the model works. Activity 2 (Revised & Humanized) Shared folder and connecting to shared folders on macOS You can connect your Mac to shared computers and file servers on your network, including Mac and Windows computers that have file sharing turned on, and servers that use protocols such as SMB. You can connect to a computer or server by browsing. You do this in a Finder window by clicking Connect As. If you’re connecting to a Mac that has screen sharing turned on, and you have the right privileges, you can also click Share Screen. You can connect as a guest, a registered user, or using an Apple account. If asked, enter your username and password, then select the volumes or shared folders on the server. Another way is connecting by entering the server address. Click Connect to Server, type the address, and click Connect. This also gives you the same three connection options: Guest, Registered User, or Apple Account. You can reconnect to recent servers, and there are a few ways to do that. In Finder, you can add shared computers or network areas to your list of favorites. If you can’t locate a shared computer or server or connect to it, it may not be available, or you may not have permission to connect.
